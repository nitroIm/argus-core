### 🚨 4 ДЕТЕКТОРА

| # | Тип | Пороги | Что означает |
|---|---|---|---|
| 1 | **pump_dump** | рост +5% + объём ×3 + падение -3% | Классический pump & dump |
| 2 | **cross_exchange** | OKX vs CoinGecko > 0.5% | Разница цен между источниками |
| 3 | **wash_trading** | объём ×10 при range < 0.5% | Активность без движения цены |
| 4 | **stop_hunting** | хвост > 50% от range | Прокол уровня с возвратом |

---

### 🔄 ЛОГИКА РАБОТЫ

```
Каждый час в :30 → anomaly.py
  ├─ Читает 48ч свечей из candles
  ├─ Читает cross_check за 1ч
  ├─ Для каждой монеты (BTC, ETH):
  │    ├─ Пробегает 4 детектора
  │    ├─ Проверяет: была ли такая аномалия за 24ч?
  │    └─ Если нет → anomaly_log + Telegram
  └─ Закрывает соединение
```

**Дедупликация:** 24 часа. Одна аномалия не спамит.

```

```

### 🗄 anomaly_log — структура

```sql
id           SERIAL
symbol       TEXT           -- BTCUSDT
timestamp    TIMESTAMPTZ    -- момент аномалии
anomaly_type TEXT           -- pump_dump / wash_trading / cross_exchange / stop_hunting
severity     TEXT           -- high / medium / low
details      JSONB          -- конкретика (change_pct, volume_ratio, ...)
notified     BOOLEAN        -- отправлено ли в Telegram
created_at   TIMESTAMPTZ    -- когда записали
```

**Проверка в Supabase:**
```sql
SELECT symbol, anomaly_type, severity, created_at, details
FROM anomaly_log
ORDER BY created_at DESC
LIMIT 10;
```

### 📌 КЛЮЧЕВЫЕ ПРАВИЛА v3

1. **Строки в коде ≤ 60 символов** — иначе телефон рвёт при копипасте
2. **Cron-порядок:** collect :00 → enrich :15 → detect :30
3. **`notify()` отдельно от `log_anomaly()`** — сейчас stop_hunting пишет в БД без Telegram
4. **Детекторы идемпотентны** — 24ч защита от спама
5. **`crypto/detect/`** — отдельная ветка от enrich

---

### ⚠️ ИЗВЕСТНЫЕ ОГРАНИЧЕНИЯ v3

1. **stop_hunting** не шлёт Telegram — только БД
2. **Мало данных** (45 свечей за 48ч) — детекторы могут пропускать
3. **Пороги** могут быть слишком жёсткими / мягкими — калибруются опытом
4. **Cross-exchange** — редко срабатывает, так как цены синхронные
5. **Wash trading** — почти не бывает на BTC/ETH (только на мелких монетах)
