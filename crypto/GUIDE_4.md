### 📈 ГРАФИКИ — 3 ТИПА

**1. Свечи** (BTC/ETH):
- Зелёные/красные свечи
- Support/Resistance пунктиром
- Объём внизу
- Подпись: цена, %, high, low, support, resist

**2. Паттерн 0/1:**
- Столбики вверх = 1 (рост), вниз = 0 (падение)
- 50 часов истории
- Подпись: сколько up/down, max streak, топ n-грамма

**3. Markov матрица:**
- 2×2: `from DOWN/UP → UP/DOWN`
- Значения 0.0 — 1.0
- Подпись: P(1|0), P(1|1) + интерпретация
- **Тёмный текст** — видно на светлом фоне

**Как читать Markov:**

| Клетка | Что значит |
|---|---|
| from DOWN → UP | После падения — вероятность роста |
| from UP → UP | После роста — продолжение роста |

**Если P(1\|0) > 0.58** — mean reversion (после падения отскок).
**Если P(1\|0) < 0.42** — momentum (падение продолжается).

### 🎵 АУДИОКНИГИ

**Файл:** `scripts/personal_audio.py`

**Что делает:**
- Читает PDF из `personal_books/`
- PyPDF2 → текст
- gTTS → mp3
- Режет на сегменты по **45 минут**
- Отправляет в Telegram
- **mp3 удаляет** после отправки
- PDF остаётся в `personal_books/`

**Требования на VPS:**
```
pip install gTTS PyPDF2
apt install ffmpeg
```

**Команды (в боте):**
```
/audio          - список книг
/audio имя      - сделать аудио (RU)
/audio имя --en - из EN оригинала
```

**Работает через GitHub Actions** (`personal_audio.yml`):
- Бот → dispatch → Actions → mp3 в Telegram
- VPS не нагружается
- Никаких mp3 на VPS (только в TG)

### ⚠️ ВАЖНЫЕ ТЕХНИЧЕСКИЕ МОМЕНТЫ

**1. `crypto_enrich.yml` должен иметь `contents: write`**

Иначе JSON не коммитятся → утренний отчёт видит «нет данных».

**2. `crypto_collect.yml` должен иметь `contents: write`**

То же для кэша CoinGecko.

**3. Часовой пояс Калининград = UTC+2**

Круглый год, без перехода на летнее.

**4. Cron GitHub на приватных репо «душится»**

Запуски бывают ~4-6 раз в сутки вместо 24. Это нормально.

**5. При копипасте с телефона строки длиннее ~55 символов рвутся**

Писать код короткими строками.
