# 04. ATR — Average True Range

## 1. Что это такое
ATR — индикатор волатильности.
Придуман Уэллсом Уайлдером в 1978 году.
Он показывает средний размах цены за период.
ATR не показывает направление движения.
Только силу и амплитуду колебаний.

## 2. Как считается
True Range (TR) — это максимум из трех:
1. High - Low текущей свечи.
2. |High - Close прошлой свечи|.
3. |Low - Close прошлой свечи|.

ATR = среднее значение TR за N периодов.
Стандартный период: 14 свечей.
Формула сглаживания: скользящая средняя.

## 3. Как читать ATR
Высокий ATR = высокая волатильность.
Низкий ATR = рынок затих, спокойствие.
Рост ATR = движение усиливается.
Падение ATR = рынок готовится к рывку.

Важно: ATR не говорит "вверх" или "вниз".
Он говорит только "далеко" или "близко".

## 4. Применение в трейдинге

### А. Стоп-лосс по ATR
Классика: стоп = 2 * ATR от входа.
Для LONG: стоп = entry - (2 * ATR).
Для SHORT: стоп = entry + (2 * ATR).
Это защищает от рыночного шума.
Обычный шум не выбьет тебя из сделки.

### Б. Размер позиции
Чем выше ATR, тем меньше позиция.
Формула: риск / (ATR * стоимость пункта).
Пример: депозит $100, риск 1% = $1.
ATR = 500. Стоп = 1000 пунктов.
Размер позиции = $1 / 1000 = 0.001.

### В. Цели по ATR
Тейк-профит = 2 * ATR или 3 * ATR.
Соотношение риск/прибыль = 1:2 или 1:3.
Это стандарт для внутридневной торговли.

## 5. ATR и другие индикаторы

### ATR + Боллинджер
Полосы сужаются, ATR падает.
Это сигнал скорого пробоя.
После пробоя ATR резко растет.

### ATR + RSI
RSI показывает перекупленность.
ATR показывает, насколько сильно движение.
Вместе дают полную картину.

## 6. Ловушки (Traps)
1. ATR запаздывает.
   Он основан на прошлых данных.
   Резкий рост ATR может быть уже поздним.
2. ATR не работает в боковике.
   В узком диапазоне ATR низкий.
   Стопы по ATR будут слишком близко.
3. Игнорирование таймфрейма.
   ATR на 1H и 1D сильно отличается.
   Всегда указывай таймфрейм.

## 7. Практические правила
- Период по умолчанию: 14.
- Для крипты: 14 (стандарт).
- Для скальпинга: 7 или 10.
- Для свинга: 14 или 20.
- Стоп не ближе 1.5 * ATR.
- Тейк не меньше 2 * ATR.

## 8. Пример на крипте
BTC, дневной график.
ATR = $800.
Цена = $60,000.
Стоп для LONG = $60,000 - $1,600 = $58,400.
Тейк = $60,000 + $2,400 = $62,400.
Это безопасная сделка по волатильности.

## 9. Главная мысль
ATR — это твой компас по волатильности.
Без него стопы ставятся наугад.
С ним — по логике рынка.
Всегда сочетай ATR с трендовыми индикаторами.
