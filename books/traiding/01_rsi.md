# RSI — Relative Strength Index

## Что это

RSI — осциллятор, который показывает силу
движения цены. Придуман Уэллсом Уайлдером
в 1978 году. Показывает значение от 0 до 100.

Формула (упрощённо):

  RSI = 100 - (100 / (1 + RS))

  где RS = средний рост / среднее падение
  за N периодов (обычно 14)

Интерпретация:
  0-30   — перепроданность (возможен отскок)
  30-70  — нейтральная зона
  70-100 — перекупленность (возможна коррекция)

## Как читать

Классическое правило:
  RSI < 30 → покупать
  RSI > 70 → продавать

НО это работает только в боковике.
В тренде RSI может быть 80 неделями.

Пример:
  BTC растёт 3 недели подряд, RSI = 82.
  Классическое правило говорит «продавай».
  Но цена продолжает расти.
  Причина: сильный тренд, покупатели
  перебивают продавцов каждый час.

Правильное использование:
  1. Смотреть RSI в контексте тренда
  2. RSI > 70 в восходящем тренде — норма
  3. RSI < 30 в нисходящем тренде — норма
  4. Сигнал появляется только при дивергенции

## Дивергенции — главный сигнал

Дивергенция = расхождение между RSI и ценой.

Бычья (bullish) дивергенция:
  Цена: новый минимум
  RSI:   минимум выше предыдущего
  → возможен разворот вверх

Медвежья (bearish) дивергенция:
  Цена: новый максимум
  RSI:   максимум ниже предыдущего
  → возможен разворот вниз

Пример медвежьей:
  1 час: цена $85000, RSI 78
  2 час: цена $86500, RSI 82 (новый high)
  3 час: цена $88000, RSI 76 (не догнала)
  4 час: цена $89000, RSI 72 (не догнала)
  → дивергенция, сигнал на SELL

Сильная дивергенция: RSI падает, а цена
растёт уже 3-4 свечи подряд.

## Комбинации с другими сигналами

RSI работает ЛУЧШЕ в паре:

RSI + Volume:
  RSI > 70, но объём падает → ложный сигнал
  RSI > 70, объём растёт → подтверждение

RSI + LS ratio:
  RSI > 70 + ls_ratio > 1.5 (толпа в лонгах)
  → высокая вероятность разворота вниз

RSI + Funding:
  RSI > 70 + funding положительный высокий
  → лонги платят шортам, возможен сквиз

RSI + Order book:
  RSI > 70 + ask-heavy (продавцов больше)
  → подтверждение SELL

## Ловушки

1. RSI может быть обманут:
   Слабый объём + RSI 75 = ложный
   
2. RSI может быть 90 в сильном тренде:
   Не продавать только по RSI
   
3. Дивергенции бывают тройные:
   После первого расхождения цена может
   ещё 2 раза обновить экстремум
   
4. На 1h свечах RSI шумнее, чем на 4h:
   На 1h — 60% ложных сигналов
   На 4h — 35% ложных
   На 1d — 25% ложных

## Практика для ARGUS

В симуляторе учитываем:
  RSI > 70 + ls_long_extreme
  → голос за SHORT (вес 0.4)

  RSI < 30 + ls_short_extreme
  → голос за LONG (вес 0.4)

  RSI + дивергенция
  → голос за разворот (вес 0.6)

  RSI в одиночку
  → игнорируем (без подтверждения)

## Итог

RSI — мощный, но одинокий индикатор.
Работает только в комбинации:
  1. С трендом (старший таймфрейм)
  2. С объёмом
  3. С sentiment (LS ratio, funding)
  4. С дивергенцией

Одна RSI = 50% winrate.
RSI + 3 подтверждения = 65-70%.
